      Been working on impriving how tests work. Up until now, they could only be in a flat directory, no structure. I've switched to walking the directory and any sub-directories when running all the tests. So I can structure tests a bit better and group them in directories. The idea is to be able to run all tests at once, by just giving the root dir, or just a pack of tests by giving their sub-dir. Of course running individual tests still work. Testing is hard work, but it's already saved my bacon a few times.
